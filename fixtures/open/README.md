# Intentionally-open fixtures

Shapes that are open BY DESIGN, for the non-solid flag (`docs/NON-SOLID.md`).
Not shipped to Pages as product files, and not loaded by the app's library.

Every file is generated by `tools/nso_open_make_fixtures.js` from literals and
closed-form functions of literals — nothing random — and committed so the
suite runs from a clean checkout.

```sh
node tools/nso_open_make_fixtures.js           # rewrite them
node tools/nso_open_make_fixtures.js --check   # byte-diff against the tree
```
