# Breakaway-support coupon plate

Generated by `tools/breakaway_coupons.py` with its defaults (`npm run
coupons:plate`). Not hand-edited: `npm run coupons:test` fails if these files
differ from a fresh run, so regenerate and commit rather than editing.

| file | what |
| --- | --- |
| `breakaway_coupon_plate.3mf` | the plate: 24 coupons / 48 objects, Bambu Studio project with the two joint-transition pauses baked in. Open as a **project**, not import. |
| `breakaway_coupon_map.txt` | plate position -> (geometry, gap/overlap, pause) table, plate map, notes |
| `breakaway_coupon_map.json` | the same plus per-object ids, names, verify() reports, volumes, bounding boxes |

Full write-up: `docs/BREAKAWAY-COUPONS.md`.
